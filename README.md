# Exercicio_Logica_C

Repositório com exercícios práticos de lógica de programação escritos em C, criados para consolidar os conceitos estudados durante a graduação em **Análise e Desenvolvimento de Sistemas**.

## 📁 Exercícios

| Arquivo       | Descrição                                                      |
| ------------- | -------------------------------------------------------------- |
| `Escola.c`    | Cálculo de notas e média de alunos                             |
| `Registros.c` | Uso de `struct` para armazenar informações de um carro à venda |

## 🛠️ Como executar

Os projetos foram desenvolvidos no **Visual Studio** (Windows). Para rodar:

1. Abra o Visual Studio
2. Vá em **File → Open → File** e selecione o arquivo `.c` desejado
3. Pressione **Ctrl + F5** para compilar e executar

## 🧠 Conceitos praticados

- Variáveis e tipos de dados
- Estruturas condicionais e de repetição
- Funções
- Structs (registros)
